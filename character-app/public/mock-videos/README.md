# Mock 视频资源目录

本目录用于存放开发阶段使用的预设视频文件。

## 需要的资源文件

### Stage 4: Living Avatar

1. **revealing.mp4**
   - 用途：Character Revealing 视频（角色首次展示）
   - 生成时机：Stage 2 选择模板后开始生成
   - 建议时长：5-10 秒
   - 描述：展示角色从虚无中逐渐显现的过程

2. **lipsync.mp4**
   - 用途：Lip-Sync 视频（角色说话自我介绍）
   - 生成时机：Stage 3 提交照片后开始生成
   - 建议时长：10-15 秒
   - 描述：角色对口型说自我介绍的视频

3. **transition.mp4**
   - 用途：Transition 视频（过渡转场）
   - 生成时机：Stage 4 用户确认名字后播放
   - 建议时长：3-5 秒
   - 描述：从 Onboarding 过渡到角色主页的转场动画

## 临时解决方案

在没有真实视频文件的情况下，可以使用以下方式：

1. **使用占位符视频**：创建简单的纯色/渐变视频作为占位符
2. **使用现有视频**：复用项目中其他地方的视频文件
3. **跳过视频播放**：在开发阶段暂时跳过视频播放，直接显示静态图片或文本

## 生产环境

生产环境将使用 FAL API 实时生成这些视频：
- Revealing 视频：基于用户选择的模板和 Gemini 生成的 prompt
- Lip-Sync 视频：基于 Gemini 生成的自我介绍文本
- Transition 视频：预设的通用转场效果

## 注意事项

- 所有视频文件应为 MP4 格式
- 视频分辨率建议：720p 或 1080p（适配移动端）
- 视频码率：适中即可，保证加载速度
- 文件大小：单个视频建议不超过 5MB
